
AIM
To obtain and plot the drain characteristics and transfer characteristics of an NMOS transistor using circuit simulation software (Cadence Virtuoso, ADE-L), and to use the gm/ID method-ology to design the device for a target bias current.

Result
The drain and transfer characteristics of the NMOS device were obtained, the region of operation was verified from the DC operating point, and the device was sized using the gm/ID methodology to achieve I_{D} = 1 mA at gm / I * D = 8
